# 坦克大战 · Tank Battle

一个纯 HTML5 Canvas 实现的经典《坦克大战》（Battle City）网页小游戏。**单文件、零依赖**，用浏览器打开 `index.html` 即可游玩。

## 玩法

操控绿色坦克消灭所有敌方坦克，同时守住地图底部的金色基地（🦅 鹰）。基地被摧毁或生命耗尽即游戏结束。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| 空格 / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 重新开始 |

## 特色

- 🧱 砖墙可摧毁，钢墙不可摧毁，水面坦克无法通过，草丛可隐藏坦克
- ⭐ 火力升级（满级可击穿钢墙）、❤️ 生命 +1、🛡 护盾、💣 清屏炸弹
- 敌人 AI、多关卡递进难度、分数与最高分（`localStorage` 保存）
- 复古像素风格 + Web Audio 音效

## 运行

直接双击 `index.html`，或启动一个本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
